## Description
A starter template for a Stack Simulator built with HTML, CSS, Bootstrap, jQuery, and JavaScript. It displays the values of a JavaScript Stack class as visual blocks. The Push, Pop, Peek, and Clear buttons are not connected to the stack yet.
